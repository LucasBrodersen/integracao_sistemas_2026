# Registo de decisões

Cada decisão de integração relevante fica num ficheiro próprio (`NNN-titulo.md`), no estilo dos Architecture Decision Records:

- **Contexto**: o problema e as condicionantes.
- **Alternativas**: as opções consideradas.
- **Decisão**: a opção escolhida e porquê.
- **Consequências**: o que melhora, o que piora, o que fica por resolver.
- **Referências**: a literatura que fundamenta a decisão.

Os artefactos de cada tópico remetem para estas decisões, que depois alimentam o Projeto Integrador.
