# Integração de Sistemas 2026/2027

Repositório de trabalho da unidade curricular **Integração de Sistemas (22295)** do Mestrado em Engenharia Informática e Tecnologia Web (UAb/UTAD).

Autor: Lucas Brodersen

## Objetivo

Guardar e versionar os artefactos produzidos ao longo da UC, desde o diagnóstico do Tópico 1 até ao Projeto Integrador, para que a evolução de cada análise e de cada decisão de integração fique rastreável.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `topico-1-compreender-integracao/` | Diagnóstico do ecossistema e matriz de integração |
| `topico-2-corba-edi/` | Tecnologias tradicionais: CORBA e EDI |
| `topico-3-soa-xml-web-services/` | SOA, XML/XSD, SOAP/WSDL |
| `topico-4-middleware-mom-esb/` | Middleware, MOM e ESB |
| `topico-5-ebxml-ebms-ws/` | ebXML, ebMS e Web Services de 2.ª geração |
| `projeto-integrador/` | Projeto Integrador |
| `decisoes/` | Registo das decisões de integração |
